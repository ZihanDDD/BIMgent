## 7 Troubleshooting

| Symptom | Fix |
|---|---|
| **Can’t reshape beyond a limit** | Min/max or code rules (e.g., 2R+G) are active; adjust in **Stair Settings** or disable limits temporarily. |
| **Need a simple one-off stair** | Use **Simple Stair** tool for quick placement. |
| **Need to reuse the same stair setup** | Open **Stair Settings ▸ Preferences/Transfer**, **save as symbol**, insert elsewhere. |
